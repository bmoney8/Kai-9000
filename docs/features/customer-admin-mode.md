# Customer and Admin Settings Modes

Settings open in **Customer Mode** by default. Customer Mode keeps everyday assistant preferences and behavior accessible through the General and Agent tabs while hiding provider setup, tools, integrations, and host administration. General and Agent content remains unchanged in both modes; Admin Mode controls the additional tab destinations. The **Admin Mode** switch at the top of Settings reveals all existing settings tabs, including configured services, tools, integrations, and (where enabled) sandbox settings.

The selection is stored in the app's existing settings store. It persists across app restarts and does not alter any hidden settings; switching back to Customer Mode only hides advanced controls.
